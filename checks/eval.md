# Exit gate

Run this on the finished text before you return anything. Answer every applicable
item with pass or fail. **Any fail means fix the text and run the gate again.** Do
not return a draft with a known fail and a note explaining it.

Keep this gate internal. Do not print the checklist, the count, or the per-item
verdicts unless the user asks to see the working.

Items are grouped by what they protect. The register column says where each applies:
**V** Voice, **P** Plain, **X** Precise.

---

## 1. Honesty (all registers, no exceptions)

| # | Check | V | P | X |
|---|---|---|---|---|
| 1.1 | Did the rewrite add no fact, name, number, date, statistic, quote, citation, source, cause, frequency, or ranking that is absent from the source or the user? | yes | yes | yes |
| 1.2 | Did the rewrite lose no claim, condition, exception, or scope qualifier that the source stated? | yes | yes | yes |
| 1.3 | Is every hedge at its original strength, with nothing promoted to certainty and nothing invented as certainty? | yes | yes | yes |
| 1.4 | Are all opinions, feelings, and admissions in the text the writer's own, with none manufactured to sound human? | yes | yes | yes |
| 1.5 | If a needed detail was missing, did you ask or use a simpler sentence, rather than filling the gap with something plausible? | yes | yes | yes |

A fail here is not a style problem. It is a fabrication, and it is the only kind of
failure this skill treats as disqualifying rather than fixable in place.

## The two closing questions

Ask these last, in your own words, and answer them honestly before you return
anything:

1. **What in this still reads as machine-written?** If the answer is not "nothing",
   fix it and re-run the gate.
2. **Did I add or lose any fact, name, number, date, quote, citation, or claim?** Any
   addition or loss is an error, not a stylistic choice.

Optional mechanical backstop: `scripts/tellscan.sh <file>` greps for the tells that a
regex can actually catch, which is items 6.1, 6.2, 6.3, 6.10, 4.20, and part of 4.1.
It cannot judge the rest. A clean scan is not a pass.
